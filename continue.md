# Continue Working (Agent Hand-off)

This file is a checkpoint prompt intended for a new agent (or a continuation run) to pick up where the last session left off.

## What to check first

1. **Review open tasks**
   - Open `tasks.md` and look for any items that are not marked `[x]`.
   - Identify the highest-priority remaining task.

2. **Review the latest iteration report**
   - Read the most recent `iteration_*.md` file (e.g., `iteration_4.md`) to understand what was completed and what is still in progress, also `summary.md` could help.

3. **Review the documentation**
   - Read context and rules in `agent.md`.
   - Read `docs/init.md`, go deeper if needed, to understand how the framework is structured.

4. **Check for user Replies**
   - Open `questions.md` and see if there are answered items that helps the task.
